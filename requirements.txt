# The Python dependencies of the ML part and the tool suite.
#
#     pip install -r requirements.txt
#
# Before this file the repository recorded its dependencies NOWHERE — no
# requirements.txt, no pyproject.toml, and no .md file mentioning
# `pip install`. Anyone cloning it met `ModuleNotFoundError` one package at a
# time, and had to guess which versions worked.
#
# Pinned with `>=` rather than `==`: this is a student project, not a live
# service, so hard-pinning would break this file over time faster than it
# would help. The numbers here are the versions that have ACTUALLY been
# through the whole check suite.

# ── Database ──────────────────────────────────────────────────────────────
# A pure-Python MySQL driver. PyMySQL rather than mysqlclient, because
# mysqlclient needs a C compiler and MySQL's development libraries — neither
# of which is present on a Windows machine.
PyMySQL>=1.2.0

# ── Machine learning ──────────────────────────────────────────────────────
# The three Stage 2 algorithms and the feature scaler.
scikit-learn>=1.9.1
# Writing and reloading a trained model (`ml/artifacts/*.joblib`).
joblib>=1.6.0
numpy>=2.4.6

# ── ML service ────────────────────────────────────────────────────────────
# The four internal endpoints of `API_SPECIFICATION.md` §8 — `ml/api.py`.
fastapi>=0.138.0
uvicorn>=0.49.0
pydantic>=2.13.4

# ── Time zone ─────────────────────────────────────────────────────────────
# `ml/time_vn.py` needs the IANA time zone database for `Asia/Ho_Chi_Minh`.
# Linux and macOS ship it; **Windows does not**, so without this package
# `zoneinfo.ZoneInfo` throws `ZoneInfoNotFoundError` at module load.
tzdata>=2026.6; sys_platform == "win32"
